# The Meeting That Should Have Been One Line

Entry for the make.fun competition
[The Meeting That Should Have Been One Line](https://make.fun/competitions/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c):
write the single sentence that could have replaced an entire pointless
meeting.

`main.ts` (Node 22.18+) writes one sentence to `/output/entry.txt`:

> There is no update, the deadline hasn't moved, and we just spent an hour discovering that together instead of reading it in one email.

134 characters, one sentence, no context needed: the meeting had no update
and no moved deadline, so the only thing it produced was an hour spent
learning that together — the exact email everyone avoided sending.

Run it locally with `node main.ts`.
